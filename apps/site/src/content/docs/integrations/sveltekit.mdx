---
title: SvelteKit
description: How to embed XenolithGraph in a SvelteKit app via the WebComponent or Svelte adapter. Browser-only — gated behind the `browser` flag.
---

XenolithGraph ships a **Svelte adapter** (`@xenolith/svelte`) and a **framework-agnostic Web Component** (`@xenolith/wc`). Both run only in the browser, so SvelteKit needs to be told to skip them on the server.

## Install

```sh
pnpm add @xenolith/editor @xenolith/svelte pixi.js
# or, for the framework-agnostic web-component path:
pnpm add @xenolith/editor @xenolith/wc pixi.js
```

`pixi.js` is a peer dependency.

## Pattern 1 — Svelte adapter (recommended)

```svelte
<!-- src/routes/editor/+page.svelte -->
<script lang="ts">
  import { browser } from '$app/environment'
  import { onMount } from 'svelte'

  let Editor: any = null
  onMount(async () => {
    if (browser) Editor = (await import('$lib/Editor.svelte')).default
  })
</script>

{#if Editor}
  <svelte:component this={Editor} />
{:else}
  <div style="height:100vh;background:#121212;"></div>
{/if}
```

```svelte
<!-- src/lib/Editor.svelte -->
<script lang="ts">
  import { XenolithGraph } from '@xenolith/svelte'
  import { myGraph } from '$lib/data'
</script>

<XenolithGraph
  className="xeno"
  onReady={(editor) => { editor.loadJSON(myGraph); editor.fitView() }}
/>
```

## Pattern 2 — Web Component (framework-neutral)

```svelte
<!-- src/routes/editor/+page.svelte -->
<script lang="ts">
  import { browser } from '$app/environment'
  import { onMount } from 'svelte'

  let host: HTMLDivElement
  onMount(async () => {
    if (!browser) return
    await import('@xenolith/wc') // registers <xenolith-graph>
    const editor = host.querySelector('xenolith-graph')! as any
    editor.addEventListener('ready', (e: CustomEvent) => {
      e.detail.editor.loadJSON({ /* … */ })
      e.detail.editor.fitView()
    })
  })
</script>

<div bind:this={host} style="height:100vh">
  <xenolith-graph class="xeno"></xenolith-graph>
</div>
```

## Disable SSR for editor routes

If a route ONLY renders the editor:

```ts
// src/routes/editor/+page.ts
export const ssr = false
```

Use this when the route's only purpose is the editor — keep SSR enabled for content-heavy routes.

## Why no SSR mode

The renderer needs WebGL + a real `<canvas>`. There's no static-HTML output mode. If you need a server-rendered preview of a graph (a thumbnail in a list, an OG card), call `editor.exportImage()` on the client and upload the PNG.

## Vite config — dedupe PIXI

If you import PIXI from multiple places, keep a single physical copy:

```ts
// vite.config.ts
export default defineConfig({
  resolve: { dedupe: ['pixi.js'] },
  optimizeDeps: { include: ['pixi.js'] },
})
```

PIXI's extension registry throws "Extension type X already has a handler" if you load it twice — same trap we hit in our own monorepo.
