请参阅[英文版本](../../../guides/react/) — `@xenolithengine/graph-react` 适配器的完整 API:
`<XenolithGraph>`, `useEditor`, `useNodes` / `useEdges` / `useSelection` / `useViewport` /
`useGraphJSON` / `useUndoRedo` / `useEditorEvent`, 编辑器内组件 (`<XenolithPanel>`,
`<XenolithButton>`, `<XenolithControls>`, `<XenolithMiniMap>`), 自定义 React widget 使用
`reactWidget(Component)`, 通过 `on*` props 处理事件。
