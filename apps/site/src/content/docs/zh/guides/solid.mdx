请参阅[英文版本](../../../guides/solid/) — `@xenolithengine/graph-solid` 适配器的完整 API:
指令 `use:xenolith={props}`(携带编辑器实例的 `on:ready`、事件 `on:node-click`,
payload 位于 `event.detail`。一个冒号; `on:node:click` 无法通过 Vite 依赖扫描)、通过 `createXenolithStores()` 的信号 store(`nodes` / `edges` /
`selection` / `viewport` / `graphJSON` / `undoRedo`、`nodesState()` 含 `setNodes` 与 `setEdges`)、命令式原语
`createXenolithGraph(el, props)`。
