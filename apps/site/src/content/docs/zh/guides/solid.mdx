请参阅[英文版本](../../../guides/solid/) — `@xenolithengine/graph-solid` 适配器的完整 API:
指令 `use:xenolith={props}`(携带编辑器实例的 `on:ready`、带冒号的事件 `on:node:click`,
payload 位于 `event.detail`)、通过 `createXenolithStores()` 的信号 store(`nodes` / `edges` /
`selection` / `viewport` / `graphJSON` / `undoRedo`、受控三元组 `nodesState()`)、命令式原语
`createXenolithGraph(el, props)`。
