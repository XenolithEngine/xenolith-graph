请参阅[英文版本](../../../guides/svelte/) — `@xenolithengine/graph-svelte` 适配器的完整 API:
action `use:xenolith={props}`(带 payload 的类型化 `on:*` CustomEvents、携带编辑器实例的
`on:ready`)、通过 `createXenolithStores()` 的响应式 store(`nodes` / `edges` / `selection` /
`viewport` / `graphJSON` / `undoRedo`、受控三元组 `nodesState()`)、命令式原语
`createXenolithGraph(el, props)`。
