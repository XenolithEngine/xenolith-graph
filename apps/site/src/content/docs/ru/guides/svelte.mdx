См. [англоязычную версию](../../../guides/svelte/) — там полное API адаптера
`@xenolithengine/graph-svelte`: action `use:xenolith={props}` (типизированные `on:*` CustomEvents
с payload, `on:ready` с инстансом редактора), reactive-stores через `createXenolithStores()`
(`nodes` / `edges` / `selection` / `viewport` / `graphJSON` / `undoRedo`, контролируемый триплет
`nodesState()`), императивный примитив `createXenolithGraph(el, props)`.
