См. [англоязычную версию](../../../guides/wc/) — там полное API `@xenolithengine/graph-wc`:
явная `register(tag?)`, атрибуты (`minimap`, `fit-on-load`, `disable-grid`,
`resize-to-window`, `snap`) отдельно от JS-свойств (`theme`, `graph`, `zoomBounds`,
`isValidConnection`), события `ready` + все 25 событий редактора как same-named CustomEvents
(включая preventable `-ing` с `cancel()`), lifecycle (disconnect → destroy) и SSR-заметку.
