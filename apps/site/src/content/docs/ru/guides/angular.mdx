См. [англоязычную версию](../../../guides/angular/) — там полное API адаптера
`@xenolithengine/graph-angular`: почему сервис, а не библиотечный компонент (Angular-библиотеки
с компонентами требуют partial compilation через ng-packagr — сырые декораторы падают в AOT),
`XenolithGraphService` (DI без декораторов, `mount()`/`destroy()`), RxJS-поверхность (`editor$`,
`nodes$`/`edges$`/`selection$`/`viewport$`/`graphJSON$`, `canUndo$`/`canRedo$`, типизированный
`on$()` на все 25 событий, контролируемый триплет `nodesState()`), рецепт host-компонента.
