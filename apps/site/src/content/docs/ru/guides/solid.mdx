См. [англоязычную версию](../../../guides/solid/) — там полное API адаптера
`@xenolithengine/graph-solid`: директива `use:xenolith={props}` (`on:ready` с инстансом
редактора, события `on:node-click` с payload в `event.detail` — одно двоеточие, иначе
сканер зависимостей Vite не парсит JSX), сигналы через
`createXenolithStores()` (`nodes` / `edges` / `selection` / `viewport` / `graphJSON` /
`undoRedo`, `nodesState()` с `setNodes` и `setEdges`), императивный примитив
`createXenolithGraph(el, props)`.
