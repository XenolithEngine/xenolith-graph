См. [англоязычную версию](../../../guides/react/) — там полное API адаптера `@xenolithengine/react`:
`<XenolithGraph>`, `useEditor`, `useNodes` / `useEdges` / `useSelection` / `useViewport` /
`useGraphJSON` / `useUndoRedo` / `useEditorEvent`, in-editor компоненты (`<XenolithPanel>`,
`<XenolithButton>`, `<XenolithControls>`, `<XenolithMiniMap>`), `reactWidget(Component)` для
кастомных виджетов на React, и события через `on*` props.
