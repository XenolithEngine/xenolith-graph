First public **BETA** of XenolithGraph — an embeddable, AI-native node-graph editor for the web with its own visual identity (no React-Flow look-alike).

The 18 `@xenolithengine/graph-*` packages are live on npm. Install with one command:

```sh
npm install @xenolithengine/graph-editor pixi.js
```

The public API in [`STABLE-API.md`](https://github.com/XenolithEngine/xenolith-graph/blob/main/STABLE-API.md) is the surface we plan to freeze at v1.0 — **it is NOT frozen yet**, so pin an exact version if you adopt now. Breaking changes are still possible in any 0.7.x.

### What ships

- Headless `core`, WebGL `render-pixi`, full `editor`, themes (Xen + Liquid Glass + Holographic + Synthwave)
- First-class React and Vue adapters (hooks/composables + panel components + custom-widget wrappers); thin starter adapters for Svelte, Solid, Angular, Web Components
- MCP server (`@xenolithengine/graph-mcp-server`) — 24 tools + 2 resources for Claude Desktop / Cursor / LangChain
- Auto-layout (Dagre + ELK), step debugger, time-travel, plugin host, save/export
- Initial touch / mobile support (pinch, two-finger pan, long-press, drawer chrome)
