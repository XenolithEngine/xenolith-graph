v0.7.0-beta.6 — the "face of the trust boundary" beta: the agent-proposal mode from beta.5 gets its human UI, the docs stop lying, and the API-freeze machinery turns on. The public API in [`STABLE-API.md`](https://github.com/XenolithEngine/xenolith-graph/blob/main/STABLE-API.md) is still **NOT frozen** — pin an exact version if you adopt now.

### Added

- **Proposal review panel (ADR 0007's missing half).** Connect an agent with `mode: 'propose'` and a badge surfaces while its edits wait; clicking opens the built-in review panel — every pending op with tool, args digest, predicted effect and client identity (labelled transport-provided, not authenticated). **Approve all** lands the whole batch as ONE atomic undo step; per-entry ✕ and Reject all discard. `editor.chrome.{showProposals, hideProposals, isProposalsVisible}`, declarative `<XenolithProposalQueue>` in React and Vue. See it live: [playground/?demo=agent&mode=propose](https://graph.xenolith.studio/playground/?demo=agent&mode=propose).
- **Ctrl+F graph search.** The insert palette finds types to SPAWN; the new search finds nodes you already built — title or type (case-insensitive), arrows + Enter, picking selects and centers. `editor.findNodes()` shares semantics with the MCP `find_nodes` tool; `editor.focusNode(id)` centers. On a 58k-node graph this is not a luxury.
- **Accessibility slice 1.** The canvas host is a focusable `role="application"`; arrow keys walk the selection node-to-node, Enter opens the properties sidebar, Esc peels overlays one layer at a time, and a polite live region announces selection changes. Screen-reader traversal of the WebGL scene itself remains open — tracked in the README roadmap.
- **API-freeze mechanics.** `stripInternal` is live: `editor.app`, `editor.commandBus`, `editor.graph` and the renderer-introspection helpers are gone from the shipped `.d.ts` (runtime untouched). New narrow read surface `editor.graphNodes()` / `editor.graphEdges()` — what the selector hooks are built on. A CI gate now parses STABLE-API and fails when a documented `editor.<member>` doesn't exist on the class (its first run caught `editor.disconnect` — documented since v0.4, never implemented).
- **object_info-driven ComfyUI import.** `importComfyWorkflow(workflow, { objectInfo })` — pass the ComfyUI server's `/object_info` and widgets arrive with real names, combo options and numeric ranges instead of the positional `param N` heuristic (which remains the fallback); a provenance report accounts for every value. The comfy-demo takes `?comfy=http://localhost:8188`.

### Fixed

- MCP README documented 5 of the 26 tools; now the full table (read / audited-mutating / view-chrome), 3 resources, and the proposal-mode honest limits. Repo-wide count corrections (26 tools · 3 resources, 25 events / 7 preventable). README test badges are now generated from the suites (`scripts/update-test-counts.mjs`) — they had drifted to 1012/142 against a real 1278/117.
- `find_nodes` (MCP + human search) now matches the EFFECTIVE node title (renamed → schema title fallback) and takes types exact-but-case-insensitive.
- Playground e2e moved to port 5199 (strict) — Vite's default 5173 was repeatedly stolen by sibling projects, which Playwright's `reuseExistingServer` then silently tested against.
