v0.7.0-beta.9 — the pre-freeze API conveniences land (`connect()` in the React Flow `onConnect` shape, `setEdges` on every controlled triple), a locked graph stops leaking edit gestures, and the last example pages get framework source tabs. The public API in [`STABLE-API.md`](https://github.com/XenolithEngine/xenolith-graph/blob/main/STABLE-API.md) is still **NOT frozen** — pin an exact version if you adopt now.

### API conveniences (pre-freeze)

- **`editor.connect({ source, sourceHandle, target, targetHandle })`** — the object form React Flow hosts already type in `onConnect`. `source` / `target` accept a node or its id; the handle fields go through the same `PinSelector` resolver as the positional form (pin id → label → numeric index → `'in'` / `'out'`, `null` = the node's single pin of that direction). The positional call is unchanged; both share one implementation.
- **`setEdges` on the controlled state** — React, Vue, Svelte, Solid, and Angular. Same contract as `setNodes`: one call is one undo step, endpoints compare by node id and pin id, and a changed endpoint is a remove-then-add of that edge id.
- **Flat viewport and history verbs stay through v1.0.** `editor.fitView`, `editor.setViewport`, `editor.screenToWorld`, `editor.undo`, `editor.redo`, `editor.canUndo`, `editor.canRedo` are no longer scheduled for removal — that is the call shape hosts already type. `editor.view` and `editor.history` remain aliases.
- **Solid directive events are kebab names** (`on:node-click`, not `on:node:click`): two colons fail Vite's esbuild dependency scan. `solidEventName()` maps the canonical colon names automatically.

### A locked graph cannot be edited through the back door

`setInteractive(false)` already blocked drag, connect, and marquee. It did **not** block Tab, double-click, the insert button, an already-open palette, the context menu, or the delete / undo / paste / duplicate shortcuts — every one of them still edited the graph. Those gestures now no-op while locked, and locking closes the palette, context menu, and sidebar. The programmatic API (`insertNode`, `applyChanges`, …) stays available — lock gates the human, not the host.

### Examples

The showcase gallery (`image-pipeline`, `audio-synth`, `llm-builder`, `heatmap`, `mcp-live`, `step-debugger`, `time-travel`, `graph-diff`) and the `stress-test` / `diagram` / `connection-validation` pages now ship Vue, Svelte, Solid, and Angular source tabs. `custom-widgets` ships Vue and Svelte — the adapters with a widget bridge; Solid and Angular snippets for `image-pipeline` and `llm-builder` mount a DOM widget controller inline. Each page still mounts **one** live canvas (the React island); other chips switch the code only, and the frame says so.
