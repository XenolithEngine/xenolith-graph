v0.7.0-beta.5 — an incremental beta focused on host execution, edge styling, sidebar-only widgets, and a big export fix. The public API in [`STABLE-API.md`](https://github.com/XenolithEngine/xenolith-graph/blob/main/STABLE-API.md) is still **NOT frozen** — pin an exact version if you adopt now.

### Added

- **`evaluateGraph()` in core — run your own nodes.** The editor still does not execute graphs; now the headless core gives hosts the missing half: a topological dataflow pass where you supply one compute function per node and output-pin values thread into the next node's inputs. See the guide [Run your own nodes](https://graph.xenolith.studio/guides/run/) and the updated [Run-graph tutorial chapter](https://graph.xenolith.studio/learn/).
- **Default edge options.** `editor.setDefaultEdgeOptions({ path: 'smoothstep', animated: true, … })` styles every edge document-wide; explicit per-edge options still win. `editor.getEdgeOptions(edgeId)` reads the merged result.
- **Sidebar-only widgets.** Set `inNodeBody: false` on a widget schema: it renders in the properties sidebar and on the node it contributes no body row — declutter node bodies without losing the control.
- **`openSidebar` for custom DOM widgets.** React/Vue custom-widget mounts now receive an `openSidebar()` callback, so a button on a node can pop the node's properties panel.

### Fixed

- **Wide-graph export.** `exportImage()` on graphs larger than the GPU `MAX_TEXTURE_SIZE` used to produce blank PNGs; the export now renders in GPU-sized tiles and stitches the result (regression-tested with a ~21,000-px-wide graph).
- Docs accuracy pass (CI-coverage claims, MCP tool count 25, stale pre-v0.1 text).

### Removed — breaking

- The experimental theme packages `@xenolithengine/graph-theme-holographic` and `@xenolithengine/graph-theme-synthwave` are gone (announced as experimental since introduction; the playground theme switcher now offers Xen / Daylight / Liquid Glass). If you imported them, migrate to `graph-theme-xen`, `graph-theme-daylight`, or `graph-theme-liquid-glass`.

### Internal

- Editor internals: the monolith's macro/template/dive orchestration, pointer gestures, and comment handling now live in `Subgraph`, `PointerController`, and `CommentController` modules (no public API change, +38 unit tests). This is prep for future renderer work — nothing you need to do.
