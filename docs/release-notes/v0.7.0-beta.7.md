v0.7.0-beta.7 — the "every adapter speaks your framework" beta: all six framework adapters reach contract parity with Learn pages, the zero-dependency core joins the stripInternal family, the editor monolith starts shrinking, and the propose-mode demo stops acting — you make the decision now. The public API in [`STABLE-API.md`](https://github.com/XenolithEngine/xenolith-graph/blob/main/STABLE-API.md) is still **NOT frozen** — pin an exact version if you adopt now.

### Track A — adapters, complete

The yardstick is new: [`docs/ADAPTER-CONTRACT.md`](https://github.com/XenolithEngine/xenolith-graph/blob/main/docs/ADAPTER-CONTRACT.md) defines what "an adapter exists" means (mount with all nine `XenolithProps`, typed events derived from `EDITOR_EVENT_NAMES`, the full reactive hook/store set including the controlled triple, in-editor components, widget bridge, test parity, Learn page). All six now pass it:

- **Vue — full parity with React** (the reference). Typed object-form emits (payload types reach vue-tsc/Volar), `useXenolithGraph` mount composable, the controlled triple `useNodesState()` (ADR 0006), all nine props synced (`resizeToWindow` was silently dropped; `isValidConnection` didn't exist), hook tests 7 → 27 incl. a real-editor integration suite.
- **Svelte — runtime + components.** `on:ready` with the editor, typed `on:*` action events, `createXenolithStores()` (nodes/edges/selection/viewport/graphJSON/undoRedo + `nodesState()`), and — behind `@xenolithengine/graph-svelte/components` (Svelte 5) — the panel family and `svelteWidget`. The action and stores work on Svelte 4.
- **Angular — the honest shape.** The old shipped `XenolithGraphComponent` **could not work in any default (AOT) app** (raw decorator classes need ng-packagr partial compilation) — removed, replaced by the decorator-free `XenolithGraphService`: plain-class DI, RxJS reactive surface, `on$('node:click')`, `nodesState()`. Hosts write a thin component; the Learn page ships the recipe.
- **Solid — runtime.** Typed directive (`JSX.Directives`), `on:ready`, `createXenolithStores()` signal bag, `nodesState()`. En route: the package's vitest resolved solid-js's SERVER build where `createEffect` is a no-op — fixed with browser conditions.
- **Web Component v2.** Full attribute dictionary (`snap`, `resize-to-window` added), events derived from `EDITOR_EVENT_NAMES` (the hand-list had silently lost 12 of 25 — including every preventable veto), `ready` event (the poll-`el.editor` recipe is dead), attribute removal actually clears the prop.
- **React** (reference) polished: `useUndoRedo` module-level, `useNodesState` diff shared via adapter-core's new `diffNodesToChanges`.

Every adapter has a Learn page (EN canonical + RU/ZH), and `STABLE-API.md`'s adapter table matches reality again.

### Track M — the monolith shrinks, core joins the family

- **ADR 0008: `Graph.internals()` friend surface.** The editor's command bus reaches `Graph`'s ten internal mutators through an exported `GraphInternals` interface + one accessor; the concrete members now strip from the shipped `.d.ts`. **Every package in the repo compiles with `stripInternal`** — core was the last holdout.
- **`DomWidgetLayer` and `ExportController` extracted** verbatim from the 5.5k-line editor index (−310 lines so far; handle-bag pattern, zero behavior change, editor suite untouched).

### The demo stops acting

[`?demo=agent&mode=propose`](https://graph.xenolith.studio/playground/?demo=agent&mode=propose) used to auto-click its own Approve button — the trust boundary flashed by in ~1.5s. Now the session opens the review panel and **waits for you**: Approve all lands the batch as ONE undo step; Reject all ends with "the agent changed nothing", history clean. The one-undo guarantee is yours to feel (Ctrl+Z once reverts all 14 agent nodes).
