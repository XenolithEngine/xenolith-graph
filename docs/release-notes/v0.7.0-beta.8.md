v0.7.0-beta.8 — the examples gallery stops pretending every chip is a live canvas, and the same demos now have Vue, Svelte, Solid, and Angular source. The public API in [`STABLE-API.md`](https://github.com/XenolithEngine/xenolith-graph/blob/main/STABLE-API.md) is still **NOT frozen** — pin an exact version if you adopt now.

### Examples

Each example page still mounts **one** canvas (plain JS when that demo has it, otherwise React). A framework chip that is not that canvas switches the code tab only, and the frame says so: "Canvas stays on JS" or "Canvas stays on React".

Source tabs added for two-way binding, load, viewport, theming, export image, built-in widgets, the canvas level-bar widget, conditional widgets, type conversions, breadcrumb dive, preview nodes, edge paths, nested layout, and auto-layout.

The site build runs `apps/site/scripts/check-example-snippets.mjs` first. A snippet that is not listed, a listed path that is missing, the word "soon", or a Svelte file that does not compile fails the build.

Custom DOM widget bridges stay React-only in this beta. Solid and Angular still have no widget bridge — use a canvas widget or `editor.chrome`.

### Docs

The README adapter rows, the MCP count (26 tools, 3 resources), and the gzip table match a fresh `pnpm size` from 2026-09-30: editor **91.8 KB**, core 8.7, render-pixi 18.3, react 2.8, about 340 KB with the PIXI peer. Under the 120 KB editor ceiling. The React Flow migration guide (EN/RU/ZH) documents the commit-time controlled protocol (`useNodesState` / `nodesState` / `applyChanges` / `graph:changed`) that shipped in beta.6.

`VERSION` in core, render-pixi, the themes, and the MCP server identity had stayed at `0.7.0-beta.5` through the last two package bumps. They match this tag.
